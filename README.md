# Scoop bucket for Tessera

[Tessera](https://github.com/ahmmedrejowan/tessera) is a desktop library for game assets: every
pack you collect, with its licence and its source on record.

```powershell
scoop bucket add tessera https://github.com/ahmmedrejowan/scoop-tessera
scoop install tessera
```

This installs the portable build, so nothing is written outside Scoop's own folder. `scoop update
tessera` to move to a newer version, `scoop uninstall tessera` to remove it.

The manifest here is written by Tessera's own release workflow, from the checksums published with
each release. Problems with the app itself belong in
[its issues](https://github.com/ahmmedrejowan/tessera/issues).
